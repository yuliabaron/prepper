Privacy Policy

Prepper Telegram Assistant · Effective 21 October 2026

Who this applies to

Prepper is a personal assistant used only by its owner. It does not accept other users, and it does not collect data about anyone else.

What Google data it accesses

  • Google Calendar: reads, creates, edits and deletes events in the owner's calendar, and sends invitations to attendees the owner names.
  • Google Docs: reads and edits documents the owner asks about.
  • Google Sheets: reads and edits spreadsheets the owner asks about.
  • Google Drive: read-only, used only to find a document or spreadsheet by its name.

How the data is used

Google data is used only to carry out the owner's own requests. To understand each request, the text of the request and the event, document or sheet content it needs are sent to Anthropic's Claude API. The data is not used for advertising, profiling or any other purpose.

Storage

Prepper does not keep copies of Google data. The only thing it stores is the Google sign-in token, kept on the owner's own computer. Conversation history is held in memory only and is deleted when the program restarts or after 3 hours without messages.

Sharing

Google data is never sold, and is not shared with anyone except the Claude API processing described above. There are no ads and no analytics.

Google API Services User Data Policy

Prepper's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be removed at any time at myaccount.google.com/permissions.
